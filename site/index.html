Crawl → index → retrieve → analyze, measured

A small, end-to-end retrieval-augmented generation pipeline over the Flask documentation, running entirely on local, free models, with the same corpus also ingested into an AnythingLLM workspace and measured there. Everything on this page was precomputed; no model is called when you load it.

Pipeline

Each stage is a small Python module with one job. Another LLM backend means one class; another vector store means replacing the index storage and the dense scoring step (see "Extending" in the README).

CrawlReads robots.txt first, paces every request (≥1 s, including redirects), validates each URL and redirect hop against one prefix, caches HTML.
ChunkWalks the Sphinx section tree; API entries stay separate; code blocks stay whole unless larger than the 1,500-character bound, then they are split with fences re-balanced; every chunk keeps a breadcrumb and deep link.
Embednomic-embed-text via ollama, with document/query task prefixes.
RetrieveDense cosine + BM25, fused with reciprocal-rank fusion (top 5).
AnalyzeLocal LLM, passages delimited as untrusted data; output validated against a JSON schema; every citation is checked in code against the passage it cites.

Example: AnythingLLM sources → this repo's analysis layer

Output of python -m rag_demo anythingllm ask "…". AnythingLLM ran the workspace query and returned its sources. Those sources, with their AnythingLLM scores and document ids kept as provenance, were passed to the same validation and citation-checking layer as the local pipeline.
